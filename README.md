# Vietnamese Student Feedback Sentiment Analysis

## Overview

This project investigates the impact of class imbalance
on Vietnamese student feedback sentiment classification
using the UIT-VSFC dataset.

## Research Objectives

- Analyze sentiment class distribution.
- Investigate the impact of imbalanced data.
- Evaluate traditional machine learning and deep learning models.
- Compare resampling and class weighting techniques.
- Improve classification performance on minority classes.

## Dataset

UIT-VSFC: Vietnamese Students' Feedback Corpus.

Sentiment classes:
- Negative
- Neutral
- Positive

## Models

- Logistic Regression
- Recurrent Neural Network (RNN)

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- Macro F1-score
- Confusion Matrix
